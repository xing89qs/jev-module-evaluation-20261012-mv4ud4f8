最新试验：四个是非问题，取最高 P(yes)

证据支持什么，以及不支持什么

可以支持的结论

  • 当前 Jev 集成不具备替代这个广告判断模块的可靠性证据。
  • 同一封存输入下，直接判断的关键少数类别与 Agent 参考存在系统性分歧。
  • 换成高召回筛选，仍未同时获得可靠保留和显著减负。
  • 业务事实与所加载政策已对齐，不能简单将剩余分歧都解释为已知字段遗漏。

不能据此证明的结论

  • 不能证明 Jev 在所有产品、窗口或任务上永远不行。
  • 不能证明所有分歧都源自模型能力，而非任务接口、表述或上下文利用方式。
  • 不能把 Agent（用户称 6.1-sol）的参考判断当作盲审真值；本地 artifact 也不独立验证其模型身份。
  • 没有独立 gold、广告结果回测或匹配混合流程耗时；选定分歧对象是开发样本，不是留出集。

新版 Agent 在读取本轮预测前封存全部逐 ID 判断，但已接触历史 Agent / Jev 结果，并非盲审。输入一致证明的是声明的业务决策输入一致，不是两种模型的系统提示、隐含知识或推理机制一致。

当前处置：Jev shadow 已恢复，新全量实验使用四个 yes/no 问题及最高 P(yes) 汇总；仍保持 promote_execute（进入动作制定）、keep_candidate（保留或等待）、route_to_diagnostic（核实具体事实）、needs_agent（弃权交回）原有含义。不启用自动接受或 Agent 免审；金额、风险与执行仍归 Agent。旧单题四选项仅保留复现。

这份 HTML 是隔离实验评估，不是广告 pipeline 的 Phase C。本次新增一次四问版全量 Jev 试验，没有写 A*、审批、动作状态或观察计划，未为得到更高 match 进行择优重试。
